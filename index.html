Tujuan Pembelajaran
⌂

🎯 Setelah mempelajari materi Sistem Komputer, peserta didik mampu:

1Menjelaskan pengertian sistem komputer sebagai kumpulan komponen yang saling berhubungan.
2Mengidentifikasi komponen sistem komputer: hardware, software, dan brainware.
3Menjelaskan fungsi hardware berdasarkan perannya: input, proses, output, dan penyimpanan.
4Mengidentifikasi perangkat input (keyboard, mouse, scanner, mikrofon, kamera, layar sentuh).
5Menjelaskan fungsi CPU sebagai perangkat pemrosesan utama.
6Mengidentifikasi perangkat output (monitor, printer, speaker, proyektor).
7Mengidentifikasi media penyimpanan (hard disk, SSD, flash drive, cloud storage).
8Membedakan perangkat lunak sistem dan perangkat lunak aplikasi.
9Menjelaskan fungsi sistem operasi dalam mengatur sumber daya komputer.
10Menjelaskan hubungan hardware, software, dan brainware dalam sistem komputer.
11Menjelaskan mekanisme kerja komputer: input → proses → output → storage.
12Menganalisis kebutuhan perangkat sesuai aktivitas (belajar, presentasi, gambar, gim).
13Menerapkan penggunaan & pemeliharaan komputer secara aman dan sesuai prosedur.
14Menunjukkan sikap bertanggung jawab menjaga data, privasi, dan keamanan informasi.

Materi Inti — Sistem Komputer
⌂
🧩

Apa itu Sistem Komputer?

Sistem komputer adalah gabungan komponen yang saling berhubungan dan bekerja sama untuk mengolah data menjadi informasi yang berguna.

🖥️

Perangkat Keras (Hardware)

Komponen fisik komputer yang dapat disentuh, berperan sebagai input, proses, output, maupun penyimpanan data.

💿

Perangkat Lunak (Software)

Program yang mengatur kerja komputer, terdiri atas perangkat lunak sistem (sistem operasi) dan perangkat lunak aplikasi.

🧠

Brainware (Pengguna)

Manusia yang mengoperasikan, merawat, dan mengambil keputusan dalam menjalankan sebuah sistem komputer.

💾

Media Penyimpanan

Perangkat untuk menyimpan data seperti hard disk, SSD, flash drive, kartu memori, hingga cloud storage.

🔄

Siklus Kerja Komputer

Komputer bekerja melalui tahapan input → proses → output → penyimpanan (storage) secara berkelanjutan.
